테스터 설치 안내

안드로이드 폰만 해당돼요

플레이 스토어 대신 설치 파일(APK)을 직접 받아 설치해요. 처음 한 번만 설정 하나를 바꿔 주면 돼요. 5분이면 끝나요.

아이폰은 사파리 "홈 화면에 추가"로 해요 → 아이폰은 여기

  1. 1

    설치 파일 받기

    폰에서 아래 링크를 열어 clockfall.apk를 내려받아요. 크롬 · 삼성 인터넷 어느 쪽이든 괜찮아요.

    링크: [APK 링크]

    "이 유형의 파일은 기기를 손상시킬 수 있습니다" 같은 경고가 뜨면 다운로드 또는 그래도 다운로드를 눌러요. 플레이 스토어 밖에서 받는 파일이면 늘 뜨는 안내예요.

  2. 2

    "출처를 알 수 없는 앱" 설치 허용

    다운로드가 끝나면 알림이나 다운로드 목록에서 파일을 눌러요. 처음이면 "보안을 위해 이 출처의 알 수 없는 앱은 설치할 수 없도록 설정되어 있어요" 같은 창이 떠요.

    창의 설정을 누르고 → 이 출처 허용(삼성: 권한 허용)을 켠 다음 → 뒤로 가기를 누르면 설치 화면으로 돌아와요.

    창이 안 뜨고 막혔다면, 파일을 연 앱에 직접 허용해 주세요. 메뉴 이름은 기종 · 버전마다 조금 달라요. 설정 맨 위 검색창에 "알 수 없는 앱"을 검색하면 가장 빨라요.

    삼성 갤럭시 (One UI)

    설정 → 애플리케이션 → 오른쪽 위 ⋮ → 특별한 접근 → 출처를 알 수 없는 앱 설치

    목록에서 파일을 연 앱을 골라 권한 허용을 켜요.

    • 크롬으로 받았으면 → Chrome
    • 삼성 인터넷으로 받았으면 → 삼성 인터넷
    • 내 파일 앱에서 열었으면 → 내 파일

    "자동 차단" 때문에 막혔어요라는 안내가 뜨면: 설정 → 보안 및 개인정보 보호 → 자동 차단을 잠깐 끄고 설치한 뒤, 다시 켜 주세요.

    그 밖의 안드로이드 (픽셀 등 기본 안드로이드)

    설정 → 앱 → 특별한 앱 액세스 → 출처를 알 수 없는 앱 설치

    목록에서 파일을 연 앱을 골라 이 출처 허용을 켜요.

    • 크롬으로 받았으면 → Chrome
    • Files(파일) 앱에서 열었으면 → Files by Google

    설치가 끝나면 이 허용을 다시 꺼 둬도 괜찮아요. 업데이트할 때 다시 켜면 돼요.

  3. 3

    설치 · Play 프로텍트 경고

    설치를 눌러요. 그다음 Play 프로텍트가 "안전하지 않은 앱 차단됨" 또는 "인식할 수 없는 앱"이라고 경고할 수 있어요. 아직 플레이 스토어에 올리지 않은 테스트 앱이라 그래요.

    • 세부정보 더보기(또는 ⌄ 펼치기)를 누르고 → 그래도 설치를 눌러요.
    • "앱 검사 보내기"를 물어보면 보내기 · 보내지 않음 아무거나 골라도 돼요.

    홈 화면에 클락폴 아이콘이 생기면 끝이에요. 폰을 가로로 돌려서 해 주세요. 소리를 켜면 더 좋아요.

  4. 4

    업데이트 — 같은 방법으로 덮어 설치

    새 버전이 나오면 단톡방에 새 링크를 드려요. 지우지 말고 새 파일을 받아 1 → 3번처럼 그대로 설치하면 돼요. 설치 화면에 업데이트가 보이면 맞게 하고 있는 거예요.

    저장은 그대로 남아요. 앱 이름표(패키지 ID)와 서명 열쇠가 같은 새 버전이 기존 앱 위에 덮어씌워지는 거라서, 기기 안 저장은 건드리지 않아요. 저희는 테스트 내내 같은 이름표 · 같은 열쇠로 만들어요.

    "앱이 설치되지 않았습니다" · "기존 패키지와 충돌"이 뜨면 앱을 지우지 말고 단톡방에 알려 주세요. 지우면 저장이 사라져요. 저희가 확인해 드릴게요.

앱을 지우면 저장도 사라져요

지금은 저장이 폰 안에만 있어서, 앱을 삭제하면 진행도 함께 지워져요. 혹시 몰라 남겨 두고 싶으면 ☰ 메뉴 → 설정 → 저장 내보내기로 파일을 받아 두세요. 다시 설치한 뒤 가져오기로 불러올 수 있어요.

나중에 클라우드 백업이 생기면, 지웠다가 다시 설치해도 이어서 할 수 있게 돼요. 기본은 꺼져 있고, 원하는 분만 설정 → 클라우드 백업 켜기로 켜면 돼요.

아이폰은요? — 홈 화면 앱으로 해요

아이폰은 앱 스토어 대신 사파리에서 홈 화면에 추가하면 앱처럼 전체화면 · 가로로 떠요. 한 번 다 받아 두면 인터넷 없이도 돼요.

  1. 사파리로 이 링크를 열어요(크롬 · 카톡 안 브라우저 말고 꼭 사파리): [게임 링크]
  2. 아래 가운데 공유 버튼(네모에 위 화살표)을 눌러요.
  3. 목록을 내려서 홈 화면에 추가 → 오른쪽 위 추가.
  4. 홈 화면에 생긴 깨진 시계 아이콘으로 실행해요. 폰을 가로로 돌리면 돼요.

⚠ 저장이 사라질 수 있어요. 아이폰은 저장이 사파리 데이터 안에 있어서, 설정 → 사파리 → 방문 기록 및 웹 사이트 데이터 지우기를 하거나 홈 화면 아이콘을 지우면 진행도 함께 지워져요. 몇 주 동안 안 열어도 아이폰이 지울 수 있어요.

그래서 ☰ 메뉴 → 설정 → 클라우드 백업 켜기를 꼭 켜 두세요(나오면 바로). 그 전까지는 가끔 설정 → 저장 내보내기로 파일을 받아 두면 안전해요. 시크릿 창은 저장이 안 돼요.

문제가 생기면

게임 안 ☰ 메뉴 → 설정 → 버그 신고 → 복사하기를 누르고 단톡방에 붙여 넣어 주세요. 화면 캡처 한 장도 같이 주시면 최고예요.

버그 신고에 담기는 내용은 개인정보처리방침 1-3에 다 적어 뒀어요. 직접 보내기 전엔 아무 데도 안 가요.

Tester install guideEnglish

Android phones only

Instead of the Play Store, you install the game file (APK) directly. You only need to change one setting the first time. About 5 minutes.

iPhone: add it to your Home Screen from Safari → iPhone

  1. 1

    Download the file

    Open this link on your phone and download clockfall.apk (Chrome or Samsung Internet): [APK link]

    If you see "This type of file can harm your device", tap Download / Download anyway. It appears for every file from outside the Play Store.

  2. 2

    Allow "unknown apps"

    Tap the downloaded file. The first time, a box says your phone isn't allowed to install unknown apps from this source. Tap Settings → turn on Allow from this source → go back.

    • Samsung (One UI): Settings → Apps → ⋮ → Special access → Install unknown apps → pick Chrome, Samsung Internet or My Files → Allowed. If Auto Blocker stops the install, turn it off briefly in Settings → Security and privacy → Auto Blocker and turn it back on afterwards.
    • Other Android (Pixel etc.): Settings → Apps → Special app access → Install unknown apps → pick Chrome or Files by Google → Allow from this source.
    • Fastest: search "unknown apps" in the Settings search bar.
  3. 3

    Install and Play Protect

    Tap Install. Play Protect may warn about an unrecognized or unsafe app because this test build isn't on the Play Store yet. Tap More details → Install anyway. If it asks to send the app for scanning, either choice is fine.

    Play in landscape, with sound on if you can.

  4. 4

    Updating

    For a new version, don't uninstall. Download the new file and install it the same way. You should see Update.

    Your save stays, because the new version has the same package ID and the same signing key, so it installs over the old one without touching on-device data. We keep both the same for the whole test.

    If you see "App not installed" or "conflicts with an existing package", don't uninstall — tell us in the group chat. Uninstalling erases your save.

Uninstalling deletes your save

Saves live only on your phone for now. To keep a copy, use ☰ Menu → Settings → Export save, then Import after reinstalling. Once cloud backup arrives, you'll be able to pick up where you left off after reinstalling. It will be off by default; turn it on in Settings → Turn on cloud backup if you want it.

iPhone — add it to your Home Screen

On iPhone, add the game to your Home Screen from Safari and it runs like an app: full screen, landscape, and offline once everything has loaded.

  1. Open this link in Safari (not Chrome or an in-app browser): [game link]
  2. Tap Share (the square with an up arrow).
  3. Scroll down → Add to Home Screen → Add.
  4. Launch it from the broken-clock icon and turn your phone sideways.

⚠ Your save can disappear. On iPhone the save lives in Safari's website data — clearing it (Settings → Safari → Clear History and Website Data), deleting the Home Screen icon, or not opening the game for a few weeks can wipe your progress.

Turn on ☰ Menu → Settings → Cloud backup as soon as it's available. Until then, use Settings → Export save now and then. Private tabs don't save.

Something went wrong?

In the game: ☰ Menu → Settings → Bug report → Copy, then paste it in the group chat, ideally with a screenshot. What the report contains is listed in Privacy Policy 1-3. Nothing is sent unless you send it.
