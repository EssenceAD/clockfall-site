## 필드·쉘터 바닥 v2 — 럼블 톤 (2026-10-19, 테스트 피드백 §7·§8)
큰 색 얼룩만 있고 잔알갱이(풀잎·클로버·점)가 없다. 톤 후보 C(올리브·황토 + 따뜻한 그레이딩)에 맞춰 만든 것.

| 파일 | 역할 | 반복 크기 |
|---|---|---|
| field_grass.jpg | 걷는 땅 기본(올리브·황록·약간의 황토) | 6~8m |
| field_dirt.jpg | 길(큰길·골목·균열 길). 목적지를 잇는 띠 | 4~5m |
| field_sand.jpg | 공터·광장 주변·건조 지대. 풀과 큰 얼룩으로 섞어 바닥 변주 | 6~8m |

- 세 장을 스플랫맵(또는 큰 노이즈 마스크)으로 섞는다. 경계는 2~3m 폭으로 번지게, 칼로 자른 경계 금지.
- 반복 무늬가 보이면 큰 노이즈로 밝기 ±6% 얼룩만 추가. 텍스처 자체에 디테일을 더하지 않는다.
- "숨는 곳"(수풀)은 바닥 텍스처가 아니라 수풀 모델 덩어리로 표현한다.
